# HERBALIS

Boutique de compléments alimentaires (côlon & digestion, anti-chute, confort respiratoire).
Bilingue **arabe (défaut)** / **français**, thème clair / sombre.

```
npm install
cp .env.example .env
npm start
```

Atelier (réglages) : chemin secret défini par `ADMIN_PATH` dans `.env` (pas de lien public).
